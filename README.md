# Developer Portfolio

A modern, minimalist portfolio website built with Next.js 15, React 19, TypeScript, and Tailwind CSS.

## Features
- **Modern & Minimalist aesthetic** with zinc / dark-mode design system
- **Dark & Light Mode** toggle powered by `next-themes`
- **Dynamic Data Architecture** via `src/data/portfolio.ts`
- **Sections**:
  - Hero with availability badge and social links
  - Categorized Technical Skills matrix
  - Work Experience timeline
  - Featured Projects with live & GitHub links
  - Blog & writing previews
  - Functional Contact Form
  - Mobile responsive drawer menu

## Quick Start

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Customization

Simply open `src/data/portfolio.ts` and modify your personal bio, work experience, projects, skills, and links!
